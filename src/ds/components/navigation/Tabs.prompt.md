Abas para visões irmãs do mesmo objeto. Ativo marcado por sublinhado de 2px — nunca por pílula preenchida.

```jsx
<Tabs value={tab} onChange={setTab} items={[
  { value: "req", label: "Requisitos", count: 210 },
  { value: "src", label: "Fontes", icon: "folder" }
]} />
```

Em fundo tinta (`tone="ink"`) o sublinhado é limão.
