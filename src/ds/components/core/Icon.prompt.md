Glifo Lucide inline que herda `currentColor` — use para qualquer ícone de UI da Tendra.ai.

```jsx
<Icon name="shield-check" size="lg" />
```

Tamanhos: `sm` 14 (dentro de badge/chip), `md` 16 (padrão em botões e listas), `lg` 20 (nav, cabeçalhos), `xl` 24 (estados vazios). O traço é sempre 2px — não engrosse para "dar destaque"; suba o tamanho. Só nomes presentes em `assets/icons/` resolvem; qualquer outro renderiza `null`.
