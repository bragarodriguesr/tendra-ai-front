Superfície de conteúdo. Plana, borda de 1px, sem sombra — sombra na Tendra.ai é só para camadas que flutuam.

```jsx
<Card tone="paper" padding="lg">…</Card>
<Card tone="ink" radius="2xl">…</Card>
```

`paper` sobre fundo papel (o caso comum); `ink` para o bloco de produto; `ink-panel` para painéis aninhados dentro de um card tinta; `accent` (limão) só em banner promocional. `accentTop` desenha a faixa de 3px dos cards Faça / Não faça.
