Ação de ícone só — barras de ferramenta, fechar diálogo, ações de linha.

```jsx
<IconButton icon="x" label="Fechar" />
<IconButton icon="filter" label="Filtrar" variant="outline" />
```

`ghost` é o padrão dentro de listas e cabeçalhos; `outline` quando precisa se ler como controle isolado; `inverse` em fundo tinta. Use `lg` (44px) em qualquer toolbar tocável.
