Campo de texto. Foco = borda sálvia + halo sálvia de 3px; nunca azul de navegador.

```jsx
<Input icon="search" placeholder="Buscar em 4.812 respostas" />
<Input mono defaultValue="REQ-084/210" />
```

`mono` para IDs de requisito, chaves e valores técnicos. `invalid` troca a borda por `--danger` e suprime o halo.
