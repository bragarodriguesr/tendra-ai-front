# Material de referência

Esta pasta guarda documentos que **não fazem parte do artefato principal da fase atual** e foram mantidos para uso futuro.

> **Não utilizar o conteúdo desta pasta, a menos que seja pedido expressamente.** Isso vale para pessoas e para o Claude: não consultar, citar, atualizar nem tomar decisões com base nestes arquivos sem um pedido explícito.

O artefato principal desta fase é [`docs/mvp-resposta-rfp/`](../mvp-resposta-rfp/).
