# Propriedade intelectual e uso de dados

CENÁRIO SINTÉTICO PARA TESTES DO TENDRA.AI. Vereda Documental é uma empresa inteiramente fictícia. Este documento não representa empresa real. Todas as capacidades, condições, taxas, controles e evidências abaixo são inventados e não descrevem a empresa real. Não usar como proposta comercial, orientação financeira ou comprovação de conformidade.

Escopo: plataforma fictícia de emissão, gestão e inteligência documental; valores e condições apenas para avaliação do Tendra.ai.

## 1. Da plataforma

A plataforma, os modelos de checklist padrão, a documentação e a marca são da Vereda. O contrato dá ao cliente o direito de uso durante a vigência, sem transferência de propriedade.

## 2. Do cliente

Os documentos, dossiês, checklists criados pelo cliente e os dados extraídos dos documentos do cliente pertencem ao cliente.

## 3. Dados agregados

A Vereda pode usar dados agregados e anonimizados de uso da plataforma (por exemplo, tempo médio por emissor) para melhorar o serviço. Esses dados não permitem identificar o cliente nem os titulares.

## 4. Treinamento de modelos

Documentos e dados do cliente não são usados para treinar modelos de IA gerais, nem pela Vereda nem pelo provedor de IA contratado.
