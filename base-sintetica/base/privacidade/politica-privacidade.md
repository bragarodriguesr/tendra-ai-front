# Política de Privacidade e Proteção de Dados

Documento da Órbita Sistemas S.A., empresa fictícia usada para testes. Está de acordo com a Lei Geral de Proteção de Dados (LGPD, Lei 13.709/2018).

## 1. Encarregado pelo tratamento de dados

O encarregado pelo tratamento de dados pessoais (DPO) da Órbita é a Coordenação de Privacidade. O contato é feito pelo endereço privacidade@orbita.example.

## 2. Direitos dos titulares

### 2.1 Como solicitar

Os titulares podem solicitar acesso, correção, anonimização, portabilidade e eliminação de seus dados pelo endereço do encarregado.

### 2.2 Prazo de atendimento

As solicitações dos titulares são respondidas em até 15 dias corridos a partir do recebimento.

## 3. Retenção de dados

Após o encerramento do contrato, os dados do cliente ficam disponíveis para exportação por 90 dias e são eliminados em seguida.

## 4. Segurança do tratamento

As medidas técnicas e administrativas de proteção estão descritas na Política de Segurança da Informação.
