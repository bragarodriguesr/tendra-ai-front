Botão da Tendra.ai — ação primária sempre em Tinta Profunda, nunca em Limão dentro do produto.

```jsx
<Button variant="primary" icon="check">Aprovar resposta</Button>
<Button variant="secondary">Ver trilha de auditoria</Button>
```

`primary` (tinta) é a ação de produto; `secondary` é a alternativa sempre visível ao lado dela; `accent` (limão sobre tinta) é reservado a CTA de marketing — um por tela; `ghost` para ações de linha em tabelas; `inverse-secondary` quando o fundo é tinta; `danger` só para remoção destrutiva. Altura mínima 44px em `md` — não reduza para caber layout.
