Selo de estado — a peça que carrega confiança na Tendra.ai: conformidade, fonte rastreável, revisão pendente.

```jsx
<Badge tone="approved" icon="check">Conformidade OK</Badge>
<Badge tone="neutral">Fonte rastreável</Badge>
```

Sempre mono, caixa alta. `approved` usa o wash de limão com texto em Sálvia Estado (contraste em fundo claro); em fundo tinta troque para `approved-inverse`, onde o limão pode ser o texto. `accent` (limão chapado) é de marketing, não de produto.
