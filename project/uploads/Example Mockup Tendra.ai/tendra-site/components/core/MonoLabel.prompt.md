Rótulo técnico em mono — a voz "sistema" da marca: eyebrows de seção, IDs de requisito, trilha de fonte.

```jsx
<MonoLabel>10 — Aplicações</MonoLabel>
<MonoLabel size="mono" uppercase={false} tone="sage">REQ-084/210</MonoLabel>
```

`size="label"` (11px, +10% de tracking, caixa alta) para eyebrows; `size="mono"` (12px, +4%) para metadados que o usuário lê de verdade. Em fundo tinta use `tone="inverse"`.
